# Data Pipeline Guide

This document explains the flow of training data in the Intent Classifier repository. The filenames have been prefixed with numbers (`01` through `04`) to make their position in the pipeline obvious.

## The 4 Stages of Data Generation

### Stage 1: Base Source Data
**File:** `01_source_base_training_data.csv`
- **What it is:** The foundational training dataset containing raw utterances and intents.
- **Editable?** **YES.** You manually edit this file when adding entirely new intents or baseline examples.

### Stage 2: Manual Corrections
**File:** `02_source_manual_corrections.csv`
- **What it is:** A supplementary file specifically for edge-case fixes and corrections that you hand-write to fix bugs or failures identified during testing.
- **Editable?** **YES.** You manually edit this file.

### Stage 3: Auto-Augmentation
**Script:** `scripts/build_augmented_data.py`
**File:** `03_generated_augmented_phrases.csv`
- **What it is:** The Python script contains large internal "Phrase Banks" of highly conversational/situational phrases. When you run the script, it safely filters these phrases to ensure they don't leak into the evaluation sets. The phrases that pass the filter are dumped here.
- **Editable?** **NO.** This is just a reference file generated by the script.

### Stage 4: The Master Dataset
**File:** `04_GENERATED_MASTER_training_data.csv`
- **What it is:** The script (`build_augmented_data.py`) takes files `01`, `02`, and `03`, and automatically squashes them together, removes duplicates, and generates this single, massive training file.
- **Editable?** **NO.** This file is entirely overwritten every time you run the build script.

---

## How to use the Pipeline

When you want to add new intents (for example, missing ones from Dialogflow) or fix a misclassified utterance:

1. **Add your new phrases** into `01_source_base_training_data.csv` (or `02` if it's a specific correction).
2. **Re-run the build script:**
   ```bash
   python scripts/build_augmented_data.py
   ```
   This merges your new phrases and regenerates `04_GENERATED_MASTER_training_data.csv`.
3. **Retrain the models:**
   ```bash
   python packages/buildtime/nlu_training/train.py
   python scripts/train_semantic_head.py
   ```
   The trainers will automatically read the `04_GENERATED_MASTER_training_data.csv` file.
4. **Verify:**
   ```bash
   python scripts/test_holdout.py --strict
   ```
