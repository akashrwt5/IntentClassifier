# Intent Classifier

On-device intent classification for hearing aid app. Replaces Dialogflow dependency with a lightweight ONNX model that runs offline on both Android and iOS.

## Architecture

```
User speaks → Platform STT (offline) → Text → ONNX Model → Intent
```

- **Android STT**: Native SpeechRecognizer (offline mode)
- **iOS STT**: SpeechAnalyzer (iOS 26+) / SFSpeechRecognizer (older)
- **Intent Model**: TF-IDF + Logistic Regression exported to ONNX (~16KB)

## Project Structure

```
intent-classifier/
├── data/
│   ├── intent_data_new.csv    # Training data (text → intent)
│   └── unknown_data.csv       # Low-confidence inputs logged for review
├── models/
│   ├── intent_model.onnx      # Trained model (generated by train.py)
│   └── intent_labels.pkl      # Intent label mapping (generated by train.py)
├── scripts/
│   ├── train.py               # Train model and export to ONNX
│   ├── predict.py             # Inference / CLI test tool
│   └── auto_label.py          # Auto-label unknown inputs for retraining
├── tests/                     # Test scripts
├── requirements.txt
└── README.md
```

## Setup

```bash
pip install -r requirements.txt
```

## Usage

### Train the model
```bash
python scripts/train.py
```
This reads `data/intent_data_new.csv`, trains the model, prints evaluation metrics, and exports `models/intent_model.onnx`.

### Test predictions
```bash
python scripts/predict.py
```
Interactive CLI — type phrases and see predicted intents with confidence scores.

### Grow training data from unknowns
```bash
python scripts/auto_label.py
```
Reviews `data/unknown_data.csv` and appends auto-labeled rows to training data. Always review manually before retraining.

## Retraining Workflow

1. Collect low-confidence inputs from `data/unknown_data.csv`
2. Optionally run `scripts/auto_label.py` to auto-label obvious ones
3. Manually review and add new examples to `data/intent_data_new.csv`
4. Run `python scripts/train.py`
5. Check accuracy metrics in output
6. Copy `models/intent_model.onnx` to mobile app assets

## Mobile Integration

Use [ONNX Runtime Mobile](https://onnxruntime.ai/docs/tutorials/mobile/) to run `intent_model.onnx` on-device. See `scripts/predict.py` for the inference logic to port.
