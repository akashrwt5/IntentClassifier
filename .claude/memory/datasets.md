# Memory: Datasets

> Single responsibility: training/eval data lineage and rules. Full guide:

## The 4-stage lineage (English core)

| Stage | File | Editable? |
|---|---|---|
| 1. Base source | `datasets/01_source_base_training_data.csv` | YES — new intents / baseline examples |
| 2. Manual corrections | `datasets/02_source_manual_corrections.csv` | YES — hand-written edge-case fixes |
| 3. Auto-augmentation | `datasets/03_generated_augmented_phrases.csv` | NO — generated by `scripts/build_augmented_data.py` |
| 4. Master (training input) | `datasets/04_GENERATED_MASTER_training_data.csv` | NO — regenerated (01+02+03, dedup) |

`scripts/build_augmented_data.py` holds internal phrase banks, filters them so
they cannot leak into eval sets, then merges 01+02+03 into the master file.

## Multilingual data

- `data/Generated_Master_training_French_Data.csv`,
  `data/Generated_Master_training_Danish_Data.csv`, `data/MultilanguageData/`.
- Per-intent / per-language capping is applied **before** merging (avoids one
  language/intent dominating). See `multilingual/train_multilingual.py`.
- Shared normalization: `multilingual/text_norm.py`.

## Holdout / out-of-scope (never train on these)

- `data/semantic_holdout_100.csv`, `data/semantic_holdout_2.csv`,
  `data/semantic_benchmark_250.csv`.
- OOS: `data/semantic_oos.csv`, `data/semantic_oos_2.csv`.
- Per-language holdouts: `multilingual/test/{en,fr,de,da}_holdout.csv`,
  `multilingual/test/multilingual_holdout.csv`.
- Datetime parity fixtures: `tests/datetime_parity/`.
- Expansion templates exist (`*_expansion_template.csv`) for growing these sets.

## Rules

- Keep **train / holdout / OOS strictly separate**; `packages/buildtime/nlu_training/train.py` runs a
  holdout-leakage guard and fails if leaks are found.
- Low-confidence production inputs are logged to `data/unknown_data.csv`;
  `scripts/auto_label.py` proposes labels — always review before adding to 01/02.
- Never tune on the holdout. Report macro-F1 + ECE, compare to committed baselines.

## Add-a-phrase workflow

1. Add to `01_...csv` (new) or `02_...csv` (correction).
2. `python scripts/build_augmented_data.py`  (regenerates `04_...csv`).
3. `python packages/buildtime/nlu_training/train.py` (+ `scripts/train_semantic_head.py`).
4. `python scripts/test_holdout.py --strict`.
